# 地図から旅先を見つけるアプリ（試作）

地図を眺めて、思いがけない行き先を見つけ、自分の地図に育てる Flutter アプリです。

## 今回試せること

- **見つける**: 地図の表示範囲にある手作業で選んだ場所を最大5件表示します。有名な場所と少し意外な場所を混ぜ、短い紹介から詳細を開けます。国内外の計22件を収録し、地域・日英の紹介・テーマ・確認先を同梱カタログで管理します。
- **おすすめ**: 地図下部の「おすすめ」を押すと、保存した場所の近さとテーマから未保存の候補を選び、理由を示します。「お気に入り」「行きたい」を強く、「行った」を弱く反映し、同じ地域・テーマへの偏りを抑えます。少し意外な候補も混ぜます。保存履歴がないときは日ごとに候補を変えます。候補を押すと地図がその場所へ移動します。
- **残す**: 場所を「行きたい」「行った」「お気に入り」に分類し、300文字までの非公開メモを残せます。端末内の Hive に保存し、アプリを再起動しても残ります。地図を長押しすると自分の場所も追加できます。
- **自分の地図**: 保存した場所を地図と一覧で見返し、「すべて・行きたい・行った・お気に入り」で絞り込めます。
- **バックアップ**: 「設定」からマイマップをJSONファイルに書き出し、読み込めます。通常は新しい場所だけ追加します。同じ場所もバックアップの内容に戻す場合は、読み込み時に明示的に選べます。自動同期はありません。
- **既存の空港機能**: 「空港」「便」タブから従来の地域・空港検索、便検索を使えます。便データの網羅性やリアルタイム運賃は保証していません。

現在のおすすめは端末内の簡単なルールを使う試作です。旅程作成、他ユーザーの口コミ、クラウド同期は含まれていません。場所の追加方法は [カタログ編集ガイド](docs/curated-place-sources.md)、次の実装順序は [開発計画](docs/development-plan.md) に記載しています。

## 試し方

1. 起動後の「見つける」で東京の地図を動かし、ピンまたは下部のカードをタップします。
2. 「行きたい」「行った」「お気に入り」を操作し、メモを入力します。
3. 「マイマップ」で保存結果を確認し、アプリを再起動しても残ることを確認します。
4. 好きな地点を長押しして、自分の場所を追加します。
5. 「おすすめ」で候補と理由を確認し、カードを押して別の地域へ移動します。
6. 「設定」→「マイマップを書き出す」でJSONファイルを「ファイル」に保存します。別端末や新規インストール先では「バックアップを読み込む」で復元できます。同じ端末では既存の場所は通常読み飛ばされます。「既存の記録も復元する」を選ぶと、その場所の記録がファイル内の内容に戻ります。

地図表示には Google Maps の設定とネットワークが必要です。場所の紹介と保存には追加の場所検索 API キーは使いません。

## 使用技術

- Flutter / Dart
- Google Maps Flutter（地図表示）
- Riverpod（画面状態）
- Hive（端末内の保存）
- file_selector / share_plus（バックアップファイルの読み込み・共有）
- Amadeus API（既存の便検索）

## 開発環境

Flutter 3.40.0-0.1.pre で開発しています。別の Flutter バージョンで作業する場合は、先に `flutter analyze` と各対象のビルドを確認してください。

このリポジトリには API キーを含むファイルを登録していません。開発機に次のファイルを用意してください。

| ファイル | 必要な設定 |
| --- | --- |
| `.env` | `GOOGLE_MAPS_API_KEY`、`AMADEUS_API_KEY`、`AMADEUS_API_SECRET` |
| `android/secret.properties` | `googleMap.apiKey` |
| `ios/Runner/Environment.swift` | `struct Env { static let googleMapsApiKey = "..." }` |

依存関係と生成コードを準備します。

```sh
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter gen-l10n
flutter analyze
flutter test
```

Android で実行する場合は `flutter run -d <AndroidのデバイスID>`、iOS シミュレータで実行する場合は `flutter run -d <iOSのデバイスID>` を使用します。接続先は `flutter devices` で確認できます。

Android エミュレータで地図だけが表示されない場合は、端末日時と通信状態を確認してください。検証時は古いスナップショットにより日時がずれており、コールドブート後に地図が表示されました。
